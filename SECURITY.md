# Security and privacy

This experimental adapter handles local media and changes a locally built application copy. It is not a supported extension API or an operating-system sandbox.

Do not disclose credentials, session history or profile contents in an issue. For a sensitive issue, use GitHub's private vulnerability reporting if the maintainer has enabled it; otherwise publish only a minimal description without exploit details or private data and request a private contact channel.

Only the version in `supported-builds.json` is a compatibility target. Keep source and generated local output separate. Do not disable operating-system protections to run an untrusted copy.
