# v0.3.6 — Experimental source release

为Windows版Codex添加本机壁纸播放及本地创意工坊的非官方实验性项目。

## 包含功能

- 图片与视频背景，暂停、重载、静音、音量、铺满和完整显示。
- 720p/30性能副本、1080p/30均衡副本及原视频切换。
- 文字阅读底框、界面底色强度和文字颜色设置。
- 本机工坊预览、搜索、收藏、分享包导入与导出。
- 本机Wallpaper Engine发现、场景接收、隔离网页、用户参数和诊断。

## 本版修复

- WE恢复播放后源窗口遮住客户端的问题。
- 首帧尚未加载时提前显示黑色背景的问题。
- 新版侧栏额外底色和阅读复选框显示问题。

## 使用要求

固定支持Codex应用`26.1027.51404`及Windows安装包`26.1027.6604.0`，需要Windows x64、Node.js 24+和PowerShell 7+。WE场景需要自行安装Wallpaper Engine并编译捕获辅助程序，视频转码需要自行提供FFmpeg。

从自己安装的Codex在本机构建副本，具体命令见README。附件为源码包。

## 验证范围

29项自动化测试通过。部分功能已进行原生窗口检查，WE暂停恢复包含一次受控焦点与系统窗口层级检查。长期运行、全部窗口转换、完整登录后工作流和未来Codex版本仍待验证。

本版按Pre-release发布，性能数据属于指定机器与视口的短时采样。详情见`docs/VALIDATION.md`。
